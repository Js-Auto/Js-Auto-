免費 3 步驟開通 Firebase 雲端資料庫

為什麼要用 Firebase？

Google Firebase 是全球最大的雲端資料庫之一，提供永久免費額度（每天高達 50,000 次讀取、20,000 次寫入），對於二手車行網站完全免費零成本，且全台灣客人點開都能即時同步！

1

建立免費專案

前往 Firebase 控制台，登入 Google 帳號並點擊「新增專案」（例如命名為 js-auto）。

2

啟用 Firestore Database

在左側選單點擊「Firestore Database」 → 點擊「建立資料庫」 → 規則選擇「測試模式 (Test mode)」，地區選 asia-east1 (台灣) 或任一地區，點擊啟用。

3

複製網頁應用程式金鑰

在專案設定點擊新增「Web 應用程式 (網頁圖示 </>)」，複製產生的 firebaseConfig = { ... } 物件，回到後台貼上並點擊「儲存並連線」，立即完成！
